# Tech Stack

`README.md` lists the core stack. Details it omits:

- React Router runs in framework mode with SSR enabled (`react-router.config.ts`)
- `~/*` is aliased to `app/*`
- SQLite is driven by `better-sqlite3`
- shadcn/ui uses the new-york style, neutral base, lucide icons
- **Zod** for validation, **marked** + **shiki** for markdown
- **Monaco** for the instructor's markdown editor, **@hello-pangea/dnd** for drag-and-drop ordering
